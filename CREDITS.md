## Adhan audio history
- 0.2.0 bundled "Beautiful adhan.ogg" (Commons, user Adam-synagda, self-declared CC0). **Removed in 0.3.0**: licence only
  asserted by the uploader. It remains in git history of the 0.2.0 commit (history not rewritten).
- 0.4.0 bundles the ASC Leiden / van de Bruinhorst recording above, whose permission is on file with Wikimedia VRT.
  It is a field recording (hotel room, fans audible), offered as the optional "Adhan" sound; the chime stays the default.
