## Modification note (1.0.0)
The bundled adhan is a **modified** version of the source recording: audio track extracted from the .webm video,
down-mixed to mono, noise-reduced (FFT denoise + band-limit) and loudness-normalised. The modified file is licensed
**CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/). Credit: Gerard van de Bruinhorst / African Studies
Centre Leiden. A/B previews (not in the app): `adhan_original_preview.m4a`, `adhan_denoised_preview.m4a`.

## 1.0.1 change
The ASC Leiden / van de Bruinhorst Hargeisa recording (CC BY-SA 4.0, VRT 2019092710004895) used in 0.4.0–1.0.0
was **removed** from the app in 1.0.1 and replaced by the default adhan above. It remains in git history only.
