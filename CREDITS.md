## Adhan audio: not shipped (since 0.3.0)
0.2.0 bundled "Beautiful adhan.ogg" (Wikimedia Commons, user Adam-synagda, tagged CC0 "own work",
SHA-256 35fe06b0…2a79). Its only licence evidence is the uploader's own claim: the file has no embedded
licence/author metadata (only an encoder tag), and there is no independent source. The archive.org adhan items
we checked (CC0 / PD-mark) are also self-declared by uploaders. Since nothing could be verified, the file was removed
and the "Sound" alert plays the generated chime above. A real adhan recording is a later item, pending a source whose
licence can be verified independently (e.g. a government broadcaster, or a written permission from a muezzin/mosque).
