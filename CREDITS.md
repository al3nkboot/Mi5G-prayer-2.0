## Adhan audio history
- 0.2.0 bundled "Beautiful adhan.ogg" (Commons, user Adam-synagda, self-declared CC0). **Removed in 0.3.0**: licence only
  asserted by the uploader. It remains in git history of the 0.2.0 commit (history not rewritten).
- 0.4.0 bundles the ASC Leiden / van de Bruinhorst recording above, whose permission is on file with Wikimedia VRT.
  It is a field recording (hotel room, fans audible), offered as the optional "Adhan" sound; the chime stays the default.

## Modification note (1.0.0)
The bundled adhan is a **modified** version of the source recording: audio track extracted from the .webm video,
down-mixed to mono, noise-reduced (FFT denoise + band-limit) and loudness-normalised. The modified file is licensed
**CC BY-SA 4.0** (https://creativecommons.org/licenses/by-sa/4.0/). Credit: Gerard van de Bruinhorst / African Studies
Centre Leiden. A/B previews (not in the app): `adhan_original_preview.m4a`, `adhan_denoised_preview.m4a`.
